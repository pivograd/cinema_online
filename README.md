# Кинотеатр — совместный просмотр для двоих

Один фильм, одно время у всех: play, пауза и перемотка синхронизируются между участниками.
Сервер на Node.js (одна зависимость — `ws`), клиент — обычная страница, на телефоне ничего ставить не нужно.

## Запуск

```bash
npm install
# положите фильм в папку media/ (mp4: H.264 + AAC, см. ниже)
USERS="anna:пароль1;boris:пароль2" SESSION_SECRET="длинная-случайная-строка" npm start
```

Откройте http://localhost:3000, войдите, нажмите «Присоединиться к просмотру».

| Переменная       | Назначение                                              | По умолчанию |
|------------------|---------------------------------------------------------|--------------|
| `USERS`          | `логин:пароль;логин:пароль`                             | обязательна  |
| `SESSION_SECRET` | ключ подписи cookie (без него вход слетает при рестарте) | случайный    |
| `MEDIA_DIR`      | папка с фильмами                                        | `./media`    |
| `PORT`           | порт                                                    | `3000`       |
| `TRUST_PROXY`    | сколько прокси стоит перед сервером (см. «Деплой»)       | `0`          |

## Формат фильма

Телефоны надёжно играют **mp4 с H.264 + AAC**. Конвертация:

```bash
ffmpeg -i film.mkv -c:v libx264 -preset slow -crf 23 -c:a aac -b:a 128k -movflags +faststart film.mp4
```

`+faststart` обязателен: без него видео не начнёт играть, пока не загрузится целиком.
Если в `media/` несколько файлов, появится выбор фильма.

## Деплой

- Нужен хостинг с Node.js и **WebSocket** (Render, Fly.io, Railway, свой VPS). Команда запуска: `npm start`.
- Включите HTTPS (на этих хостингах он есть по умолчанию); cookie получает флаг `Secure` за прокси автоматически.
- Фильм на бесплатных тарифах часто лежит на временном диске: проверьте, что файл остаётся после рестарта (нужен persistent disk/volume), или загружайте его после каждого деплоя.
- Если сервер за прокси, задайте `TRUST_PROXY` — число прокси перед ним (за одним балансировщиком хостинга — `1`).
  Тогда IP для ограничения попыток входа берётся из `X-Forwarded-For`. Без этого все зрители видны серверу
  под адресом прокси, и 5 неверных паролей от кого угодно блокируют вход всем на 5 минут.
  Не включайте `TRUST_PROXY`, если прокси нет: заголовок подделывается, и лимит попыток можно обойти.

## Тесты

```bash
TEST_VIDEO=/путь/к/любому.webm npm test
```

Поднимает сервер, открывает двух зрителей в Chromium и проверяет логин, закрытый доступ к видео, play, pause, перемотку, дрейф и переподключение.
