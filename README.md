# Свет в окне — кинозал на двоих

Один фильм, одно время у обоих: play, пауза и перемотка синхронизируются между зрителями.
Сервер на Node.js (одна зависимость — `ws`), клиент — обычная страница, на телефоне ничего ставить не нужно.

## Запуск

```bash
npm install
# положите фильм в папку media/ (mp4: H.264 + AAC, см. ниже)
USERS="anna:пароль1;boris:пароль2" SESSION_SECRET="длинная-случайная-строка" npm start
```

Откройте http://localhost:3000, войдите и нажмите «Смотреть».

| Переменная       | Назначение                                               | По умолчанию |
|------------------|----------------------------------------------------------|--------------|
| `USERS`          | `логин:пароль;логин:пароль`                              | обязательна  |
| `SESSION_SECRET` | ключ подписи cookie (без него вход слетает при рестарте) | случайный    |
| `SESSION_DAYS`   | сколько дней устройство помнит вход                      | `30`         |
| `MEDIA_DIR`      | папка с фильмами                                         | `./media`    |
| `PORT`           | порт                                                     | `3000`       |
| `TRUST_PROXY`    | сколько прокси стоит перед сервером (см. «Деплой»)       | `0`          |

## Как это выглядит

Вход и лобби — петербургский двор-колодец в тумане: ваше окно на одной стене, окно второго зрителя напротив.
Окно загорается, когда человек в сети. Свет во дворе меняется по времени суток: вечер, ночь, туманное утро, пасмурный день.
«Смотреть» раскрывает фильм прямо из вашего окна.

В плеере:

- кто в зале — два окна вверху справа;
- общие действия видны обоим одинаково: «anna: пауза», «boris: перемотка на 1:02:15»;
- если паузу поставил не человек, а телефон (входящий звонок, отключились наушники), карточка так и говорит: «плеер встал на паузу»;
- фильм, запущенный с самого начала, стартует у обоих после общего отсчёта 3-2-1;
- если у кого-то фильм догружается, пауза ставится у всех («ждём друг друга»), а когда догрузится — продолжается с того же места;
- горячие клавиши: пробел или K — пауза, ←/→ или J/L — 10 секунд назад/вперёд, F — во весь экран, M — звук, C — субтитры.

## Формат фильма

Телефоны надёжно играют **mp4 с H.264 + AAC**. Конвертация:

```bash
ffmpeg -i film.mkv -c:v libx264 -preset slow -crf 23 -c:a aac -b:a 128k -movflags +faststart film.mp4
```

`+faststart` обязателен: без него видео не начнёт играть, пока не загрузится целиком.
Если в `media/` несколько файлов, появится выбор фильма (он меняется у обоих).

## Субтитры

Положите рядом с фильмом файл с тем же именем: `film.srt`, `film.ru.srt`, `film.en.vtt`.
Подходят `.srt` и `.vtt`; `.srt` переводится в WebVTT на лету, русские субтитры в windows-1251 тоже читаются.
Субтитры каждый включает себе сам (кнопка в плеере или клавиша C).

## На телефоне

- На iPhone удобнее открыть сервис с экрана «Домой» («Поделиться» → «На экран „Домой“»): так пропадает панель Safari.
  Войти там придётся один раз отдельно — у приложения с экрана «Домой» свои cookie.
- Кнопка «Повернуть» поворачивает плеер, если телефон лежит, а поворот экрана заблокирован.
- Кнопка «Во весь экран» на iPhone открывает системный плеер Safari: в нём не видно, кто в зале и кто нажал паузу.
- Лучше смотреть в наушниках, иначе звук фильма попадёт в созвон.

## Деплой

- Нужен хостинг с Node.js и **WebSocket** (Render, Fly.io, Railway, свой VPS). Команда запуска: `npm start`.
- Включите HTTPS (на этих хостингах он есть по умолчанию); cookie получает флаг `Secure` за прокси автоматически.
- Фильм на бесплатных тарифах часто лежит на временном диске: проверьте, что файл остаётся после рестарта (нужен persistent disk/volume), или загружайте его после каждого деплоя.
- Если сервер за прокси, задайте `TRUST_PROXY` — число прокси перед ним (за одним балансировщиком хостинга — `1`).
  Тогда IP для ограничения попыток входа берётся из `X-Forwarded-For`. Без этого все зрители видны серверу
  под адресом прокси, и 5 неверных паролей от кого угодно блокируют вход всем на 5 минут.
  Не включайте `TRUST_PROXY`, если прокси нет: заголовок подделывается, и лимит попыток можно обойти.

## Тесты

```bash
TEST_VIDEO=/путь/к/любому.mp4 npm test
```

Поднимает сервер, открывает двух зрителей в Chromium и проверяет логин, закрытый доступ к видео, play (с общим отсчётом), pause, перемотку, дрейф и переподключение.
Видео нужно не короче 40 секунд. Путь к браузеру задаётся `CHROMIUM`, например на Windows (PowerShell):

```powershell
$env:TEST_VIDEO="C:\films\test.mp4"; $env:CHROMIUM="C:\Program Files\Google\Chrome\Application\chrome.exe"; npm test
```

Иконки (`public/assets/icon-*.png`) рисуются скриптом `node scripts/icons.mjs`.
